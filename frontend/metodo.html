Método

Cómo se obtienen las predicciones

Objetivo

Este proyecto pronostica la tasa de cambio informal del dólar estadounidense frente al peso cubano. Es un mercado no regulado cuyo precio se forma en plataformas como eltoque.com. El objetivo es publicar un pronóstico a siete días, actualizado a diario, con una estimación de la incertidumbre.

Datos

La fuente primaria es la API pública de cubanomic, que agrega las cotizaciones que publica eltoque.com. Para cada día se toma la mediana de todas las cotizaciones observadas. Se usa la mediana en lugar de la media porque resiste mejor los valores extremos: si un vendedor publica un precio muy alto, la media sube, pero la mediana casi no cambia. La serie se reconstruye en frecuencia diaria y los días sin datos se rellenan con el último valor conocido.

La API consolida y publica el dato diario con uno o dos días de atraso, así que la fecha de cobertura que aparece en la cabecera puede ser anterior a hoy. El modelo trabaja siempre con el último dato consolidado disponible.

Modelado

El motor es AutoGluon TimeSeries, una biblioteca que entrena varios modelos de series temporales a la vez y combina los mejores en un ensemble. Entre los modelos que prueba están ETS, Theta, RecursiveTabular, DirectTabular y SeasonalNaive. El entrenamiento corre en CPU. El objetivo es la mediana diaria y el horizonte de predicción es de siete días.

Validación

Durante la exploración manual, los últimos 30 días de la serie se apartan del entrenamiento y se reservan como conjunto de prueba. Sobre ese conjunto, AutoGluon calcula el MASE, que compara el error del modelo con el error de un predictor que repite el valor de hace una semana. Un MASE de 1.0 significa que el modelo empata con ese predictor; por debajo de 1.0, el modelo aporta valor. El cálculo se hace sobre los últimos siete días del conjunto de prueba, que es el horizonte que se publica. El modelo también usa backtesting interno durante el entrenamiento para elegir los componentes del ensemble.

En la operación semanal, el predictor congelado se reentrena con toda la serie disponible. El monitor evalúa después las predicciones publicadas cuando ya existe un dato real.

Predicción e incertidumbre

Cada día el modelo produce una distribución de valores posibles para cada uno de los siete días siguientes, en lugar de un único número. De esa distribución se publica la media como pronóstico central y los percentiles 10 y 90 como banda de incertidumbre. El modelo estima que el valor real caerá dentro de esa banda con un 80% de probabilidad. Una banda ancha indica más incertidumbre; una banda estrecha, más confianza. El pronóstico central es el punto medio de una distribución, no una promesa.

Cadencia de actualización

El pronóstico se regenera a diario alrededor de las 08:00 hora de Cuba, con el dato más reciente disponible. Cada domingo el modelo se reentrena con toda la serie acumulada, para que incorpore el régimen de precios de la última semana. Cada tres o seis meses, o cuando el sistema detecta una degradación sostenida, se repite la exploración completa de modelos en busca de una configuración mejor. Esa re-exploración es manual y no corre en el ciclo automático.

Limitaciones conocidas

La serie disponible cubre alrededor de dos años y el mercado informal está sujeto a choques que ningún modelo estadístico puede anticipar, como cambios de política monetaria, variaciones en la disponibilidad de divisas o eventos macroeconómicos. El modelo estima el patrón reciente de la serie, no predice esos eventos. Nada de lo que aparece aquí constituye consejo financiero.

Proyecto académico y experimental. Datos: eltoque.com vía API de cubanomic.
