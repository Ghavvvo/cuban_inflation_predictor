Cómo se obtienen las predicciones

Objetivo

Este proyecto pronostica la tasa de cambio informal del dólar estadounidense frente al peso cubano (USD/CUP), un mercado no regulado cuyo precio se determina en plataformas como eltoque.com. El objetivo es producir un pronóstico de 7 días, actualizado diariamente, con una cuantificación honesta de la incertidumbre.

Datos

La fuente primaria es la API pública de cubanomic, que agrega las cotizaciones publicadas por eltoque.com. Cada día se registra un valor representativo del mercado: la mediana de todas las cotizaciones observadas ese día (el valor que eltoque.com publica como "tasa del día"). Se elige la mediana, y no la media, porque es robusta frente a valores atípicos: una sola cotización extrema (por ejemplo, un vendedor pidiendo 860 CUP) distorsiona la media, pero apenas afecta a la mediana. La serie se reconstruye en frecuencia diaria y los días sin observaciones se rellenan con el último valor conocido (forward-fill).

Existe una limitación estructural: la API consolida y publica el dato diario con uno o dos días de atraso. Por eso la "fecha de cobertura" de la cabecera puede ser anterior a hoy; el modelo trabaja siempre con el último dato consolidado disponible.

Modelado

El motor es AutoGluon TimeSeries, una biblioteca que entrena y evalúa simultáneamente una batería de modelos de series temporales — suavizado exponencial (ETS), descomposición de Theta, métodos tabulares sobre características rezagadas (RecursiveTabular, DirectTabular) y modelos estacionales ingenuos — y construye un conjunto (ensemble) ponderado con los mejores. El entrenamiento se ejecuta en CPU. El target es la mediana diaria; el horizonte, 7 días.

Validación

Para medir el rendimiento sin inflar los resultados, los últimos 30 días de la serie se apartan del entrenamiento (hold-out) y se usan exclusivamente como conjunto de prueba. Sobre esa ventana se calcula el MASE (Mean Absolute Scaled Error): el error del modelo dividido entre el error de un predictor ingenuo estacional. Un MASE de 1.0 significa "igual de bueno que repetir el valor de hace 7 días"; por debajo de 1.0, el modelo aporta valor. El modelo actual alcanza un MASE de 0.525, aproximadamente un 50% mejor que el baseline naïve. El entrenamiento usa además backtesting interno para seleccionar los modelos y ponderar el ensemble.

Predicción e incertidumbre

Cada día el modelo produce una distribución de valores posibles para cada uno de los 7 días siguientes, no un único número. De esa distribución se reporta la media (el pronóstico central) y los percentiles 10 y 90 (p10 y p90): el intervalo entre ambos es la banda donde el modelo estima que caerá el valor real con un 80% de probabilidad. Una banda ancha indica incertidumbre alta; una estrecha, confianza alta. El pronóstico central no es una promesa: es el punto medio de una distribución, y la banda es el recordatorio visible de que el futuro no es determinista.

Cadencia de actualización

Diario (~08:00 hora de Cuba): se descarga el dato nuevo y se regenera el pronóstico de 7 días. Semanal (domingo): se reentrena el modelo con toda la serie acumulada, para que incorpore el régimen de precios más reciente. Periódico (manual, cada 3-6 meses o ante degradación detectada): se repite la exploración completa de modelos en busca de una configuración mejor.

Limitaciones conocidas

La serie es corta (alrededor de dos años) y el mercado informal está sujeto a choques estructurales — cambios de política monetaria, disponibilidad de divisas, eventos macroeconómicos — que ningún modelo estadístico puede anticipar. El modelo es, por tanto, una estimación del patrón reciente, no una predicción de eventos. Nada de esto constituye consejo financiero.
